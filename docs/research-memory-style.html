群聊里的记忆、风格与表情包

给「小肥鱼」加学习系统和记忆系统之前，先看清楚这个领域里谁已经做过了、做到什么程度，以及哪些做法会反过来伤害人格。

调研对象：DSH 生态 + AstrBot 生态 本轮不改代码

一句话结论

你要的两件事，DSH 生态里没有现成方案；AstrBot 生态里有成熟实现，但不能直接装过来。风格学习不建议做成「自动学群友」——已经有人认真做过，并且自己关掉了。记忆是地基，先做它。

01你要的两件事，各自什么情况

需求DSH 生态别处有没有成熟实现判断
记忆系统 部分 本机已装 dsh-fish-memory，但只按会话记，不分「谁说的」 成熟 LivingMemory、qq-agent-plus 扩展现有的，不必重写
表情包收藏 没有 一个都没有 成熟 stealer、smart_imagechat_hub 照思路自己做，别照搬视觉分类
学群友说话风格 没有 做过的都关掉了 改成离线提炼 + 人工审核

先说清楚一件事：AstrBot 和 DSH 是两个框架，插件不通用。AstrBot 那些插件值得读、值得抄思路，但代码搬不过来。反过来也一样。

02值得抄的三个实现

qq-agent-plus —— 思路最接近，值得逐条读

Node.js + node:sqlite + systemd，单进程。两处设计特别值得借：

  • 贴纸轮换进提示词：把「常用」和「一直没用上」的表情轮换着写进系统提示，条数可调。比一次性列几十个文件名聪明——不会让模型每次都挑那几个。
  • FTS5 + 中文二字切分做记忆检索。每人默认最多 50 条，手写条目不删、默认不过期。这比向量库轻太多，本地跑完全够。

它明确写了「不依赖 DSH」，是独立框架。但它的 memory/ 目录结构和 SQLite 表设计，是我们最该抄的部分。

github.com/sakurawwwxh/qq-agent-plus

astrbot_plugin_stealer —— 表情包收藏的完整形态

这是这个领域做得最完整的一个：

  • 监听群聊图片 → 用视觉模型做语义/情绪分类 → 入库
  • 有待审核池（自动进来的先不直接用，等你过一遍）
  • GIF 分镜处理（动图取关键帧判断情绪）
  • 按概率、冷却、群黑白名单发送
  • 暴露 search_meme / send_meme / steal_meme 三个 LLM 工具

github.com/nagatoquin33/astrbot_plugin_stealer

但视觉分类这一步，我建议不要照抄

每收一张图就调一次视觉模型，成本按图算，而且分类质量不稳定——同一张「无语」的图，它可能这次判成「嫌弃」、下次判成「震惊」。

你现在的做法反而更好：24 张按情绪命名的贴纸（shengqi.jpg 生气、xianqi.jpg 嫌弃），名字就是标签。零成本、零误判、可预测。

收藏功能该做的是扩充这个命名库，而不是引入自动分类。

LivingMemory —— 长期记忆的另一种权衡

向量 + 图谱检索，带 TTL 衰减。最大的特点是 enable_full_group_capture：抓没 @ 它的群聊上下文。这跟我们已经做的「群里听所有人」是同一件事，说明这个方向是对的。

但向量库对我们来说太重了。dsh-fish-memory 已经有一套「鲜活度 + 证据检索」，够用。

lxfight-s-astrbot-plugins.github.io/astrbot_plugin_livingmemory

03风格学习：为什么建议不做「自动学」

这个领域的主流做法分两层，差别很大：

做法代表项目代价稳定性
人格卡 + 读空气 personagent、MaiBot、ChatLuna 伪装群友 靠人手写，不学新东西 稳定
离线抽「声音指纹」 me.skill、Ta.Skill 要定期人工跑一次、人工审 可控
聊天记录微调 LoRA Chat-Style-Bot、WeClone 要训练、要显卡、要数据 高保真但重
在线自动学群友 qq-agent-plus 曾做过 已停用 被作者放弃

最值得注意的一条证据

qq-agent-plus 曾经做过「黑话研究流水线」——从群聊里学黑话、学语气。作者后来说得很干脆：流水线已停用且不能再开，相关库不再创建，提示词也不再塞黑话。

一个认真做过这件事的项目，最后把它关掉了。原因是明摆着的：群里来个人说几句脏话，它跟着学；来个人刷黑话，它也学。人格会漂、会退化——而你现在这套「可爱傲娇小鲸鱼」是逐字调出来的。

所以风格这件事，正确形态是离线 + 审核 + 可回滚：

  1. 定期（比如每周）跑一次，让它读这个群最近的对话
  2. 产出一份候选清单：常出现的群梗、口头禅、说话节奏
  3. 你看过，决定要不要进人设。不要就扔掉
  4. 进人设的部分单独成段，随时能删

这跟「在线自动学」是两回事：一个是你决定它学什么，一个是群友决定它学什么。

06建议路线

顺序有讲究：记忆是地基，风格是在记忆上面长出来的。先做风格，它没有素材可用。

  1. 01
    记住「谁是谁」
    给 fish-memory 加一层群友画像：QQ 号 → 昵称 / 别名 / 口头禅 / 爱好 / 跟群里谁熟。qq-agent-plus 的 memory/ 结构可以照抄。这一步做完，后面所有东西才有地基。
  2. 02
    表情包收藏，但按你的方式
    不要视觉模型自动分类（贵、不准）。改成：群里有人发图 → 入库待选 → 你（或它自己按名字）给个情绪标签 → 进 _stickers/。你现有 24 张的命名方式就是正确形态，要做的是让它能自己扩充。
  3. 03
    风格：离线提炼，你审核
    每周跑一次，总结这个群最近在说什么、有什么梗，产出候选清单。你看过决定要不要进人设。走 systemPrompt.context（照 feiyu-mood 的做法），不破坏前缀缓存，随时能撤。
